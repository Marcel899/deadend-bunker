# Sound effect credits

Files are trimmed, mono, loudness-matched MP3 conversions of the originals.

## CC0 1.0 (public domain, no credit required)

From the Raco Labs SFX pack (https://github.com/racolabs/sfx), which collects:

- `shot-*`, `rifle-*`, `heavy-*`: The Free Firearm Sound Library, "Prepared SFX Library" (freefirearmsfx.com)
- `boom-0..2`: Freesound CC0 recordings by Rudmer_Rotteveel (336011), xFromarge1 (520053), rodrigocswm (449434), via Raco Labs
- `launch-0`, `splat-0..1`, `buy-*`, `error-*`: Kenney (kenney.nl) Impact / Sci-fi / RPG / Interface Sounds, via Raco Labs
- `splat-2`, `pick-*`: qubodup "Impact" and Kenney Impact Sounds (opengameart.org / kenney.nl), via Raco Labs
